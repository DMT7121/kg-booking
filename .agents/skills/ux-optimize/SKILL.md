# UX Friction Reduction & Operational Speed Specialist (/ux-optimize)

## When to Use This Skill
Activate when the user runs `/ux-optimize` or asks to improve ease of use, cut down on clicks, simplify complex forms, or accelerate daily workflows.

## UX Optimization Techniques
1. **Reduce Steps**: Eliminate unnecessary confirmation modals when actions can be safely undone.
2. **Smart Defaults**: Pre-fill known inputs based on current shift, user role, or timestamp.
3. **Progressive Disclosure**: Keep primary screens clean by moving advanced or rarely touched settings into expandable panels.
4. **Form Ergonomics**: Associate labels with inputs, provide close-in error feedback, and support keyboard Enter/Tab flows.
5. **Contextual Guidance**: Use subtle tooltips and inline empty states to guide users rather than cluttering the screen with permanent instructional text.
