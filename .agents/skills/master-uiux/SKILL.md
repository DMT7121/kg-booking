# Master UI/UX & Architecture Specialist

## When to Use This Skill
Use this skill for comprehensive WebApp and Desktop application upgrades, major redesigns, UI/UX audits, and front-end architecture modernizations.

## Core Operational Workflow
1. **DISCOVER**: Inspect the tech stack, existing styling architecture, dependencies, and user personas.
2. **AUDIT**: Scan for visual hierarchy issues, layout inconsistencies, UX friction, and visual bugs.
3. **PRESERVE**: Map out all existing business logic, function names, API contracts, and routes to prevent accidental breakage.
4. **DESIGN SYSTEM**: Establish or map semantic design tokens (typography, 4-64px spacing scale, semantic colors, radii, elevation).
5. **PLAN & IMPLEMENT**: Create an implementation plan with surgical, safe changes.
6. **VALIDATE & POLISH**: Run responsive checks (320px to 1920px), a11y checks (WCAG 2.2 AA), and 1-2px detail refinement passes.

## Golden Rule
Every change must directly answer: "How does this make the user's experience or workflow better, clearer, or faster?" Preserve existing business logic at all costs.
