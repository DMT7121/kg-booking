# Desktop Ergonomics & High-Density UX Specialist (/desktop-ux)

## When to Use This Skill
Activate when the user runs `/desktop-ux` or requests desktop-focused enhancements, keyboard efficiency, data density improvements, or operational productivity tools.

## Core Desktop Enhancements
- **High Information Density**: Display more actionable data without crowding by using clean typography, subtle borders, and balanced 8/12px padding.
- **Data Table Capabilities**: Implement sticky headers, sticky ID columns, right-aligned numeric columns, and quick filter bars.
- **Keyboard Shortcuts**: Add hotkeys for frequent actions (New Item, Save, Search, Switch Tabs).
- **Command Palette**: Introduce `Ctrl/Cmd + K` modal for instant search and module navigation when appropriate.
- **Multi-Panel Layouts**: Utilize split-views and collapsible sidebars to maximize widescreen workspace.
